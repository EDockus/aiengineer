The base URL of the deployed agent — the part before /invocations. Must use https, must be a Microsoft Foundry host ending in .services.ai.azure.com, and must have no query string or fragment. Your Foundry access token is sent to this host, so it is not allowed to be any other one.

The single-page application registration this page signs in as. Public client, no secret.

The directory the registration lives in. Required: a single-tenant application cannot sign in through the shared /common endpoint.

The audience of the token sent to the agent. Always https://ai.azure.com/.default, the Microsoft Foundry data plane — a hosted agent's endpoint accepts nothing else. Your account needs the Foundry Agent Consumer role on the project or the agent.
